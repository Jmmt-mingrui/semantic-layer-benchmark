# Paper source

The Chinese Overleaf source is [semantic-layer-benchmark-zh.tex](semantic-layer-benchmark-zh.tex).

Compile it with **XeLaTeX**. The source follows the compact empirical structure of the reference paper: introduction, semantic-layer architecture, experimental setup, results, discussion, limitations, and conclusion.

This is a stage-results manuscript synchronized with the benchmark repository. It reports only verified workload and semantic-model findings. End-to-end accuracy, token usage, latency, cost, and significance are intentionally deferred until the SF1 data, Gold results, and native runtime gates are complete.

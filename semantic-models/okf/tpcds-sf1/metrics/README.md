# TPC-DS SF1 business metrics

[English](README.md) | [简体中文](README.zh-CN.md)

This directory expresses the candidate canonical metrics as OKF v0.2 Markdown knowledge concepts: 42 base metric families, 25 derived metrics, nine query-exact formulas, and mappings for all 99 questions.

These files support knowledge retrieval and reasoning; they do not assume that OKF executes SQL itself. Metric IDs, formulas, and provenance are governed by `semantic-models/canonical/tpcds-sf1/`.

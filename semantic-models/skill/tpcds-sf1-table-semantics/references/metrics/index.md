# Business metric index

Load this index after `../schema-overview.md` whenever a question asks for an aggregate, ratio, comparison, ranking, or KPI.

## Load order

1. [Base metric families](base-metrics.md) for physical aggregations and channel variants.
2. [Derived metrics](derived-metrics.md) for reusable arithmetic over base metrics.
3. [Query-exact metrics](query-exact-metrics.md) only when the mapped question requires a benchmark-specific formula.
4. [Question-to-metric map](question-metric-map.md) to resolve q01 through q99 and their analysis operations.

Keep metric IDs and formulas aligned with the canonical SF1 contract. Do not replace a query-exact metric with a more conventional business formula.

# Business metric index

For aggregation, ratio, period comparison, ranking, or KPI questions, read `index.md` first, then load the base, derived, query-exact, and 99-question mapping references only as needed.

Metric IDs, formulas, and channel variants must remain consistent with `semantic-models/canonical/tpcds-sf1/`. `analysis_operations` are query operations and must not be presented as metrics. Query-exact formulas are TPC-DS-specific and must not be silently replaced by more common business definitions.
